# Phase 17 Plan 01: Yellow Runtime Verification and Contract Closeout

## Goal

Close the v1.2 Yellow AC15 milestone by recording final automated verification, user-confirmed RPCS3 runtime smoke, and the final supported Yellow contract.

## Scope

1. Re-run full server verification:
   - `dotnet test Tests/Tests.csproj`
   - `dotnet build Host/Host.csproj -o "$env:TEMP\TaikoLocalServer-host-build"`
2. Record the user-confirmed RPCS3 Yellow runtime smoke gate for the milestone close.
3. Document the final Yellow contract:
   - supported game routes and shared startup/version ownership
   - Yellow-owned state surfaces
   - explicit non-goals and evidence gaps
   - operator data expectations
4. Mark YVER-01, YVER-02, YVER-03, and YDOC-01 complete.

## Non-Goals

- Do not add runtime behavior, routes, migrations, or tests during closeout.
- Do not invent Yellow battle behavior.
- Do not convert Banacoin compatibility into wallet, payment, coupon, settlement, receipt, or transaction authority.
- Do not add Tokkun score, crown, reward, unlock, or shop side effects.

## Verification Gate

Phase 17 is complete only when the full test project and temp-output Host build pass, and the RPCS3 runtime smoke result is recorded as user-confirmed external evidence.

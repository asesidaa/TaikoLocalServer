```csharp
public static byte[] SetPackedGrade(byte[] source, uint packedIndex, BlueDanClearGrade grade)
{
    var result = source.ToArray();
    var value = ToPackedValue(ClampGrade((uint)grade));
    var bitOffset = (int)packedIndex * 2;

    for (var bit = 0; bit < 2; bit++)
    {
        var absoluteBit = bitOffset + bit;
        var byteIndex = absoluteBit >> 3;
        if ((uint)byteIndex >= (uint)result.Length)
        {
            return result;
        }
```

### Special Modes Stay Before Shared Normal Save

**Source:** `UpdatePlayResultCommand.Blue.cs` lines 29-38; `UpdatePlayResultCommand.Yellow.cs` lines 27-42; `UpdatePlayResultCommand.Green.cs` lines 82-100 and 292-367.
**Apply to:** playresult cleanup and normal-save extraction.

Blue battle, Blue Tokkun, Yellow Tokkun, and Green ghost/AI behavior are era-local gates or hooks. Shared normal-play logic must not classify them as generic AC15.

### Log/Skip/Success For Unrecognized AC15 Shapes

**Source:** Yellow valid-stage and invalid-Dani patterns in `UpdatePlayResultCommand.Yellow.cs` lines 33-42 and tests lines 815-854.
**Apply to:** playresult refactors.

If a deterministic client payload is not recognized for a stateful path, log the existing payload facts, skip mutation, and return protocol success. Do not create an "invalid payload" failure contract unless current tests already prove one for that era.

### Mapperly Adapter-Local Wire Placement

**Source:** `Adapters.GameProtocol.*/Mappers/UserDataMappers.cs` and `InitialDataMappers.cs`.
**Apply to:** Common DTO field moves/renames.

Use Mapperly `[MapProperty]` attributes to place canonical Common fields into era-local generated wire DTOs. Do not create a shared generated wire assembly. Do not call generated protobuf `ShouldSerialize*` helpers from production mappers.

### Behavior Tests Over Source-Shape Tests

**Source:** `Tests/Ac15/*ServiceTests.cs`, `Tests/Yellow/YellowPlayResultHandlerTests.cs`, AGENTS.md testing rules.
**Apply to:** every touched plan.

Test the observable behavior: helper packing, EF rows, no-cross-era writes, no-cross-mode writes, mapper classification, response field placement, and build output. Do not assert class/file removal, source text, route inventory, Mapperly attributes, or method bodies.

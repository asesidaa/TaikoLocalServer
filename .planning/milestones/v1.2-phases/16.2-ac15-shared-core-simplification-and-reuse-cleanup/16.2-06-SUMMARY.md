- Adapters expose canonical records to shared code while keeping all EF entity construction and DbSet access era-local.
- No tests were added because this contract slice is compile- and regression-guarded by existing Dan/Dani behavior tests; later plans that move active save/readback behavior own the observable behavior test changes.

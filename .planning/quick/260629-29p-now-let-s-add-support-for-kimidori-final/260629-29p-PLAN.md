# Goal

Add KIMIDORI final game-route support for `/v05r06/chassis/*` while preserving existing KIMIDORI `/v05r00/chassis/*` behavior as the compatibility surface.

The implementation should follow the White/Murasaki final-version pattern where it is useful, but avoid forcing final wire changes onto `/v05r00`. Current evidence shows `proto/kimidori-final/taiko.proto` changes some request field numbers and adds `TaikojukuRequest/Response`, so final support needs a separate final wire surface or an equivalent compatibility-safe split.

# Constraints

- Do not copy, delete, repair, or otherwise touch `Host/wwwroot/data/kimidori/data` or any operator-supplied game-data link.
- Keep `/v05r00/chassis/*` as KIMIDORI compatibility. Existing compatibility controllers must continue to deserialize current KIMIDORI wire shapes.
- Add final game routes under `/v05r06/chassis/*` for: `playresult.php`, `baidcheck.php`, `mydonentry.php`, `userdata.php`, `crownsdata.php`, `recommend.php`, `selfbest.php`, `heartbeat.php`, `defaultsong.php`, `bookkeeping.php`, `songhash.php`, `telopcheck.php`, `gettelop.php`, `foldercheck.php`, `getfolder.php`, `mainichisong.php`, and `taikojuku.php`.
- Expose KIMIDORI final `/v05r06/chassis/startupauth.php`, `/v05r06/chassis/verupauth.php`, and `/v05r06/chassis/verupcomplete.php` because the supplied final route inventory includes startup/version suffixes under the final prefix. Leave existing shared `/v01r00/chassis/*` routes in place.
- Regenerate generated protobuf wire files from `proto/kimidori-final` only through the repo's protobuf-net/protogen pattern. Do not manually edit generated wire files.
- Controllers stay thin: deserialize final or compatibility wire DTOs, map to existing common DTOs, call Mediator/Application handlers, and map responses back.
- Business behavior stays in `Application/Handlers` and shared AC15 services.
- Taikojuku is separate from Dani. Final `taikojuku.php` should use `GetTaikojukuQuery(GameEra.Kimidori, request.GetDans ?? [])` if final wire generation exposes the request/response types.
- Do not turn KIMIDORI WebUI profile settings or `/v05r00` initial-data behavior into Taikojuku surfaces as part of this quick task.

# Summary

Implemented the review follow-up for AC15 mapper nullability.

Added `tools/generate-ac15-game-wire.ps1`, a tracked generator entrypoint that defaults to the reviewed AC15 game-wire surfaces and invokes `.tools/protogen.exe` with `+nullablevaluetype=yes`.

Regenerated White final, White legacy, Murasaki final, Murasaki legacy, and Kimidori compatibility `Game.cs` wire files. Required proto fields remain non-nullable; optional value fields now surface as nullable public properties.

Simplified playresult mappers to use direct nullable mappings for optional reward, mode, soul-gauge, hit-count, and Tokkun/difficulty tutorial fields. Non-null application DTO boundaries now explicitly default absent optional values to zero through `Ac15MapperNormalization.UIntOrZero` or `GetValueOrDefault()`.

Removed White legacy local primitive helpers in favor of shared `Ac15MapperNormalization` calls and kept local era-limit wrappers where they bind White or Murasaki limits.

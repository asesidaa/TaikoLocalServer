# Quick Task 260621-4ze: Random AC15 Recommend Song Support

## Goal

Replace static AC15 recommendation sidecar data with official-behavior random `recommend_song` responses for userdata and `recommend.php`. Do not set `recommend_best_song`, because it appends to the client's list and would exceed the official five recommendation slots.

## Source Facts

- When camera is available, the client reads `recommend_song` and `recommend_best_song`.
- If no face is detected, the client uses the userdata response. If a face is detected, it reads the separate recommend response.
- Recommended songs are picked randomly.
- `recommend_song` replaces the first client-picked song and is also random.
- `recommend_best_song` appends to the list, so this server should leave it unset.
- Existing AC15 controllers should keep transport work in controllers/mappers and behavior in Application handlers/shared AC15 helpers.

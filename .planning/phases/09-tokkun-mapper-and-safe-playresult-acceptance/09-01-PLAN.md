| Boundary | Description |
|----------|-------------|
| Blue cabinet/RPCS3 to `PlayResultController` | Untrusted direct-protobuf `PlayResultRequest` enters the server through the existing Blue playresult route. |
| Blue adapter mapper to Application DTO | Wire fields become internal `CommonPlayResultData`; raw Tokkun facts must stay facts, not trusted payment or gameplay effects. |

| Runtime request data to logs | Existing request logging and any bounded classifier log can expose client-reported payload context. |

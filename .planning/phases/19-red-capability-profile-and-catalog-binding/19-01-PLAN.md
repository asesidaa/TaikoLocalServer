# Plan 19-01 - Red Catalog/Profile Foundation

## Goal

Bind Red to existing AC15 catalog loaders and profile services without duplicating Green/Blue/Yellow catalog algorithms.

## Tasks

1. Add Red catalog abstraction and loader wrappers.
   - Create `IRedCatalog` using shared `Application.Catalog.Ac15` types where Red has no unique fields.
   - Add `CatalogExtensions.Red()`.
   - Add `RedGameDataPaths`, `RedRequiredDataFiles`, and Red loader wrappers for music, tuning, Taikojuku, event folders, telops, recommendations, movies, and customization.
   - Register `RedEraGameDataCatalog` in `Infrastructure/DependencyInjection.cs` only when Red is enabled.

2. Share customization extraction instead of copying Blue extraction.
   - Promote generic JSON extraction/write behavior to `Infrastructure/GameDataCatalog/Ac15`.
   - Update Blue to use the shared extractor.
   - Use the shared extractor for Red first-run customization JSON generation.

3. Add the Red AC15 profile.
   - Add Red features with item shop disabled.
   - Add `Ac15EraProfiles.Red` using evidence-backed Red limits.
   - Extend `Ac15CatalogSnapshotFactory` for Red without item-shop mapping.

4. Add Red server-authored data sidecars.
   - Add intentionally empty Red sidecars for supported optional catalog features.
   - Ensure Host copies those sidecars with existing content handling.

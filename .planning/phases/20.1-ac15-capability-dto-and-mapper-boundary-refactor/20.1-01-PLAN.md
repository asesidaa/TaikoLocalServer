<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Card/profile persistence -> application response | BAID handlers read shared card identity and era-owned save rows into capability records. |
| Application response -> generated wire | Adapter mappers place capability records into era-specific generated protobuf DTOs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20.1-01 | Information disclosure | Cross-era BAID readback | mitigate | Keep direct era `DbSet` lookup in handlers and preserve existing no-shared-save behavior tests. |
| T-20.1-02 | Tampering | Unsupported capability defaults | mitigate | Represent unsupported capability segments as null and do not let mappers infer era support. |
| T-20.1-03 | Denial of service | Mapper/source generation | mitigate | Preserve Mapperly strictness and run focused mapper tests plus temp-output Host build. |
| T-20.1-04 | Spoofing | Red V08R00 compatibility wire | mitigate | Preserve explicit Red V08R00 mapper coverage and do not route old-wire placement through a generic inferred path. |
</threat_model>

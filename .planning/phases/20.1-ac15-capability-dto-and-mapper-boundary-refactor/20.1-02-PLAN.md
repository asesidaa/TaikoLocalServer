<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Era save rows -> shared AC15 service | Handlers assemble era-owned save/catalog/favorite/recent facts for shared response construction. |
| Shared response -> generated wire | Mappers place AC15 capability records into Blue/Green/Yellow/Red generated userdata responses. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20.1-05 | Information disclosure | Cross-era userdata readback | mitigate | Keep concrete era table access in handlers and preserve era-owned readback tests. |
| T-20.1-06 | Tampering | Unsupported tutorial/reward/display fields | mitigate | Use nullable capability segments and canonical fields; mappers do not infer support. |
| T-20.1-07 | Denial of service | Bitset and presence mapping | mitigate | Keep fixed-width and nullable presence tests; run focused mapper and handler commands. |
| T-20.1-08 | Repudiation | Test coverage drift | mitigate | Preserve observable behavior tests and forbid source-shape/copy-only tests. |
</threat_model>

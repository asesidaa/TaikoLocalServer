## Sampling Rate

- After the BAID checkpoint: run the focused BAID command.
- After the userdata checkpoint: run the focused userdata command.
- After mapper cleanup: run the focused BAID and userdata commands plus generated-source build.
- Before closeout: run the shared AC15 regression command, full suite, temp-output Host build with emitted generated files, and record generated-source inspection.
- Max feedback latency: focused commands should remain under a few minutes; full suite/build are closeout checks.

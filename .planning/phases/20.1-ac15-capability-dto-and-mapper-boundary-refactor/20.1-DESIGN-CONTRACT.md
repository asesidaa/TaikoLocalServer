# Phase 20.1 Design Contract

This is the compact design note for Phase 20.1. It is the first file to read after `20.1-CONTEXT.md` when executing or reviewing the phase.

## Non-Negotiable Boundary

Controllers control the final assembly.

- Handlers load facts, apply business rules, and return behavior-named semantic application sections/profiles.
- Handlers do not construct generated wire DTOs.
- Handlers do not construct mapper-shaped packets, ordered capability lists, or response assembly instructions.
- Controllers instantiate the final generated wire response objects.
- Controllers set response-level and route-level constants such as result fields, BAID, content info, compatibility route fields, and other adapter-owned protocol defaults.
- Controllers choose which returned non-null semantic sections are applied to the final generated response.
- Controllers call Mapperly-generated existing-target `Apply(section, [MappingTarget] response)` methods.
- Mappers contain Mapperly declarations and mechanical conversion helpers only.
- Mappers do not aggregate responses, loop over capabilities, switch on capability/section types, decide support, decide presence, or construct final response objects.

## Accepted Flow

```text
controller request
  -> deserialize generated request
  -> map request to Mediator query
  -> handler loads era-owned runtime facts
  -> handler returns semantic application sections/profiles
  -> controller creates final generated wire response
  -> controller applies non-null sections through generated Mapperly Apply methods
  -> controller returns wire response
```

## Rejected Flow

```text
handler returns capability packets
  -> mapper loops/switches over packets
  -> mapper creates final wire response
```

This remains rejected even if individual leaf assignments are generated by Mapperly.

## Scope Guard

BAID and userdata response assembly are in scope. Playresult is input mapping and is audit-only for this phase unless a later approved phase identifies equivalent response aggregation there.

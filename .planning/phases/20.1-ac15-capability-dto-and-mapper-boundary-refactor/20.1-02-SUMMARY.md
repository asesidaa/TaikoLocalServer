# Phase 20.1 Plan 02: AC15 Userdata Capability Response Boundary Summary

**AC15 userdata readback now uses capability records before Blue, Green, Yellow, and Red wire projection.**

## Accomplishments

- Added `Ac15UserDataResponse` and grouped userdata capability records under `Application/Dtos/Ac15`.
- Split Mediator userdata handling so Nijiiro keeps `CommonUserDataResponse`, while Blue, Green, Yellow, and Red use `Ac15UserDataQuery`.
- Narrowed the shared AC15 userdata snapshot/service to value-identical common readback and moved optional capability attachment to era handlers.
- Updated AC15 userdata controllers and Mapperly mappers to project capability groups into era-owned wire DTOs.
- Updated focused behavior tests to assert grouped handler state and protocol-visible mapper output.

## Decisions Made

- `UserDataQuery` remains the Nijiiro/common query. AC15 callers must use `Ac15UserDataQuery`.
- Unsupported optional userdata capability groups stay null; mappers default or omit according to the target wire contract.
- Red Don point/reward and tutorial difficulty readback is a `Reward`/`Tutorial` capability, not era-suffixed application fields.

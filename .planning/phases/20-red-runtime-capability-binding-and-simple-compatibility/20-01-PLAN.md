# Plan 20-01 - Red-Owned Runtime State And Shared Table Bindings

## Goal

Add Red persistence and binding delegates so shared AC15 runtime writers can operate on Red-owned tables without copying Green/Blue/Yellow behavior.

## Tasks

1. [x] Add Red runtime entities.
   - Add Red save-data, song play, song best, favorite, recent, Dan score, and Dan stage score entities.

2. [x] Add Red DbContext surface.

   - Add a Red save-data factory using `Ac15EraProfiles.Red.Limits`.

| cabinet purchase request -> Application command | Untrusted item number/type/id/price values enter server-side purchase validation. |

| Blue persistence -> protocol readback | Stored purchase state controls which item bits are visible to the cabinet. |

| T-01-13 | Information Disclosure | `BaidQuery.Blue.cs` and `UserDataQuery.Blue.cs` | mitigate | Clear active-season locked song, tone, and costume bits until matching unlocked Blue shop item rows exist. |

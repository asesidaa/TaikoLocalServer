# Green Dani Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist, award, save, and read Green Dani Dojo normal and extra Dan progress separately from normal song bests while preserving existing Green selfbest behavior.

**Architecture:** Add Green-specific Dan entities and EF mapping, then layer small Green Dan helper functions for catalog id lookup, 2-bit clear flag packing, and display-slot advancement. Update Green playresult to save both normal song data and Dan data, then expose saved data through BAID/userdata and `GetDanScoreQuery.Green`.

**Tech Stack:** C# 13, .NET 10, Entity Framework Core with SQLite migrations, xUnit, Mediator handlers, protobuf-net adapter DTO mapping.

## File Structure

Create:

- `Domain/Enums/GreenDanClearGrade.cs` - Green-only clear grade enum: not clear, normal clear, gold clear.
- `Domain/Entities/DanScoreDatumGreen.cs` - parent Green Dan score/progress entity.
- `Domain/Entities/DanStageScoreDatumGreen.cs` - child per-stage Green Dan score entity keyed by stage index.
- `Application/Common/GreenDanHelpers.cs` - pure helper functions for Dan id classification, packed 2-bit flags, `GotDanMax`, and display-slot selection.
- `Infrastructure/Persistence/Migrations/*_AddGreenDanScoreData.cs` - migration generated by EF after model changes.
- `docs/superpowers/plans/2026-05-15-green-dani-flow/*.md` - this plan directory.

Modify:

- `Application/Abstractions/ITaikoDbContext.Green.cs` - expose Green Dan DbSets.
- `Infrastructure/Persistence/TaikoDbContext.Green.cs` - configure Green Dan EF tables and conversions.
- `Application/Handlers/UpdatePlayResultCommand.Green.cs` - detect Green Dani play, validate Dan id/result, upsert Dan data, update Dan flags/display.
- `Application/Handlers/BaidQuery.Green.cs` - sanitize and return Green Dan flags/max.
- `Application/Handlers/UserDataQuery.Green.cs` - compute next safe display Dan when saved value is unset, invalid, or cleared.
- `Application/Handlers/GetDanScoreQuery.cs` - inject `IGameDataCatalog` so Green Dan score reads can validate requested `challengelv` ids.
- `Application/Handlers/GetDanScoreQuery.Green.cs` - read saved Green Dan score rows instead of returning empty.
- `Tests/Green/GreenPlayResultHandlerTests.cs` - save/award/display tests.
- `Tests/Green/GreenIdentityHandlerTests.cs` or `Tests/Green/GreenUserDataMapperTests.cs` - BAID/userdata flag and display tests.
- `Tests/Green/GreenTaikojukuTests.cs` if catalog mapping needs direct coverage.

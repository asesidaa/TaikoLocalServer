# Green Item Shop Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement Green item shop support with active-season configuration, runtime shop data loading, season-scoped Don medal state, lock/unlock behavior, and an offline curation path for official shop defaults.

**Architecture:** Keep the Green shop model in Green-only catalog, persistence, handler, and mapper code. `item_type` stays the canonical protocol discriminator; `item_no` is inferred from row order. Server settings select one active season, while EF tables store player season balances and item ownership.

**Tech Stack:** C# 13, .NET 10, ASP.NET Core 10, EF Core 10 with SQLite migrations, protobuf-net, Mediator, Riok.Mapperly, xUnit.

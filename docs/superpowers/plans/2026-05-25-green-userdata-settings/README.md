# Green Userdata Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Green `is_tojiru` and local ranking difficulty settings, keep Green filtered-folder state client-owned, and fix skipped-Dan display advancement.

**Architecture:** Keep storage in the existing `UserSaveDataGreen` row and expose only `GreenIsTojiru` plus `GreenDispLevelChassis` through the Admin API and Web UI. Return the saved display-level fields in Green userdata, preserve `difficulty_played_course/star` as playresult-owned state, and change Dan advancement to use the cleared normal Dan slot as the anchor.

**Tech Stack:** C# 13, .NET 10, Entity Framework Core with SQLite migrations, xUnit, ASP.NET Core controllers, Blazor/MudBlazor Web UI, protobuf-net generated Green wire DTOs.
